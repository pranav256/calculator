# Calculator

A clean, responsive arithmetic evaluator built with vanilla JavaScript, HTML5, and CSS3, styled following the Frontend Mentor design challenge.

## Overview

- **Keyboard & Mouse Support:** Handles standard numerical inputs, operators (+, -, *, /), decimals, and clear/reset actions.
- **Display Formatting:** Features real-time expression parsing and automated operator precedence handling.
- **Responsive Layout:** CSS Grid layout adapting smoothly between mobile and desktop viewports.

## Tech Stack

- Vanilla JavaScript (ES6+)
- HTML5
- CSS3 (Flexbox & Grid)

## Getting Started

Open `index.html` directly in any modern web browser or serve via a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
